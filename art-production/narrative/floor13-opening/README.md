# Floor 13 opening cinematic art

Five 16:9 scene plates were generated for this project with OpenAI ImageGen on 2026-10-14 from original scene descriptions written for Floor 13. No third-party image was supplied as a source. The source images are retained in `source/`; runtime copies are 320×180 nearest-neighbor reductions in `public/assets/sprites/narrative/floor13-opening/`.

Runtime plates are authored as opaque cinematic backgrounds. UI text, including the message, is rendered in Phaser rather than baked into the images. The current opening sequence uses timed scene cuts with a restrained camera push, and freezes simulation until the player advances, skips, or the sequence completes.

The generated files and source prompt history are preserved as provenance. This record identifies the generation method and does not make a separate statement about public redistribution rights beyond applicable service terms.
