# Block 13 — MVP

## Player fantasy

Trapped in a corrupted blockchain building, the player descends three cursed floors to reach the street-level emergency exit. The apparent escape opens into the hidden Block 13 final chase.

## Core loop

Explore a seeded floor → find its key → the building reacts → unlock the descent → survive the next floor.

## MVP rules

- Floors: 3, descending
- Objective: key + exit per floor
- Player actions: move, flashlight, sprint, interact/search
- Threat: one stalking entity; pressure escalates on every descent
- Scares: 6–8 authored triggers, with 3–5 selected per run
- Run duration: 5–8 minutes
- Onchain flow: one transaction to start, one to submit score
