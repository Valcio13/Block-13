# Audio assets

The checked-in first-pass OGG pack and active preload list are documented in [the audio system overview](../../../docs/audio-system.md). Source URLs, creators, licensing, attribution requirements, and processing notes are recorded in [AUDIO_LICENSES.md](../../../AUDIO_LICENSES.md).

Only files present in `AUDIO_ASSET_MANIFEST` are loaded. Keep source MP3 downloads outside `public/`; check in processed game cues only, and add provenance before enabling any new asset.
